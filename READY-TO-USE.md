# A-TestChecker - Ready-to-Use Package

This package includes a one-click Windows launcher.

## Start

Double-click:

`START-A-TestChecker.bat`

The launcher starts the existing agent when Node.js is available, starts XAMPP if installed in the default location, and opens:

`http://localhost/A-Checker/`

## SMART

The application is designed to use bundled/available SMART support rather than requiring the user to manually configure a PATH entry. Hardware/controller limitations can still prevent SMART data from being exposed by Windows.

## Important

This package is a ready-to-use project package, not a digitally signed standalone EXE installer. A true single EXE build requires compiling the application for Windows.
