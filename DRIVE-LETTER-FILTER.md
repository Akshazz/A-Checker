# Drive-letter storage filter

The Storage workspace now groups physical disks once and filters their assigned volumes by drive letter.

- Physical storage selector: chooses the parent disk.
- Drive / volume selector: shows only letters actually assigned to that disk.
- C:, D:, E:, etc. automatically select the owning physical storage and show only that volume.
- The partition manager has the same physical-storage and assigned-letter controls.
- Volume cards show capacity, free space, usage, filesystem, mount point, and read-only View Files.
- No file or partition modifications are exposed.
